# GuguFotos — versão simples

## Rodar no computador

Abra o terminal **nesta pasta**, onde está o `package.json`, e rode:

```bash
npm install
npm start
```

Depois abra `http://localhost:3000`.

Painel: `http://localhost:3000/admin/login`

Senha local padrão: `gugu123`

## Onde ficam os dados

- `data/database.json` — álbuns e informações das fotos
- `uploads/` — arquivos das fotos

Não precisa de Supabase, banco externo, `.env` ou Live Server para testar localmente.
